对，**Facade Pattern 就是门面模式**（也叫"外观模式"），Facade 是英文原名，中文翻译成门面或外观，同一个东西。核心一句话：**给一堆复杂子系统提供一个统一简化入口**。

两个最经典的例子：

## 例1：编译器（GoF 书中的原版例子）
编译一个程序要经历词法分析 → 语法分析 → 生成代码，一堆子系统，客户端根本不想逐个调用。

```csharp
// 三个复杂子系统
class Scanner { public void Scan() { } }
class Parser { public void Parse() { } }
class CodeGenerator { public void Generate() { } }

// 门面：Compiler 对外只暴露一个 Compile()
public class Compiler
{
    public void Compile(string source)
    {
        var scanner = new Scanner();
        var parser = new Parser();
        var generator = new CodeGenerator();

        scanner.Scan();
        parser.Parse();
        generator.Generate();
        Console.WriteLine("编译完成");
    }
}

// 客户端
new Compiler().Compile("hello.cs");   // 一行搞定
```

## 例2：家庭影院（Head First 设计模式经典例子）
看一部电影要开投影仪、放幕布、调音响、关灯……客户端记不住顺序和细节，门面一键搞定。

```csharp
// 多个子系统
class Projector { public void On() { } public void WideScreenMode() { } }
class Amplifier { public void On() { } public void SetVolume(int v) { } }
class Lights { public void Dim(int level) { } }
class Screen { public void Down() { } }

// 门面：家庭影院统一入口
public class HomeTheaterFacade
{
    private readonly Projector _projector = new();
    private readonly Amplifier _amp = new();
    private readonly Lights _lights = new();
    private readonly Screen _screen = new();

    public void WatchMovie(string movie)   // 客户端只记这一个方法
    {
        _lights.Dim(10);
        _screen.Down();
        _projector.On();
        _projector.WideScreenMode();
        _amp.On();
        _amp.SetVolume(5);
        Console.WriteLine($"正在播放：{movie}");
    }
}

// 客户端
new HomeTheaterFacade().WatchMovie("流浪地球");
```

## 两个例子的共同点（门面识别标志）
- 客户端**只调一个方法**，内部帮你调多个子系统
- 子系统互相不知道有门面存在（门面是单向的）
- 子系统代码**不用改**，门面是额外加的一层

> 你之前那个爬虫例子（多数据源 → 统一存储）完全符合：对外一个 `Collect()`，内部协调各源。加上编译器、家庭影院，门面模式就彻底拿下了——**记住"一键搞定复杂系统"就够了**。

爬虫场景：爬虫采集多个数据源（A 网站、B 网站、C 数据库），对外只暴露一个 `Collect()` 统一接口，内部协调各源，整合成一个统一对象存储。
